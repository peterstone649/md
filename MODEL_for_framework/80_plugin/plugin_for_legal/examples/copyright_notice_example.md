## Usage Notes

This example demonstrates:
- Proper copyright notice format
- EUPL v1.2 license reference

## Adaptation Guidelines

When adapting this example:
- Update the year to current year
- Replace organization name with actual entity
- Update contact information
- Modify license if different from EUPL v1.2
- Ensure URL points to correct license text
