🤝 Contributing Translations

To contribute new translations or expand existing coverage:

1. Language Addition

Create new language directory using ISO 639-1 codes:

mkdir pt  # Portuguese
mkdir ko  # Korean
mkdir ar  # Arabic

2. Structure Mirroring

Follow the established directory structure from source content:

pt/LIVRO/
├── 10_escrita/
├── 20_AI/
└── README.md

3. Naming Conventions

Use language-appropriate transliterations for directory names: - French: LIVRE/ (Book) - German: BUCH/ (Book) - Chinese: 书/ (Book) - Spanish: LIBRO/ (Book) - Japanese: 本/ (Book) - Russian: КНИГА/ (Book)

4. Documentation

Include README.md explaining: - Translation scope and coverage - Contributors and maintainers - Quality assurance processes - Contact information for collaboration

5. Quality Standards

Adhere to established translation standards and submit for review: - Technical accuracy preservation - Cultural adaptation appropriateness - Terminology consistency - Professional quality assurance
