🚀 5-Minute Setup Process

Step 1: Prepare Your Environment (2 minutes)

# Fork the repository
git clone https://github.com/YOUR_USERNAME/md.git
cd md

# Create a new branch
git checkout -b contribution-type-your-name

Step 2: Choose Your Template (1 minute)

  • Corporate: Use examples/company_contribution_example.md
  • Stakeholder: Use examples/stakeholder_group_example.md
  • User: Use pr_template_contributors.md
  • Plugin: Use examples/plugin_developer_example.md
  • Content: Use contribution_guidelines.md

Step 3: Make Your Contribution (1 minute)

  • Copy the template
  • Fill in your information
  • Add your insights or improvements

Step 4: Submit Your PR (1 minute)

# Add your changes
git add .
git commit -m "Add [your contribution type]: [brief description]"

# Push to your fork
git push origin contribution-type-your-name

# Create PR on GitHub
# Follow the template in pr_template_contributors.md
