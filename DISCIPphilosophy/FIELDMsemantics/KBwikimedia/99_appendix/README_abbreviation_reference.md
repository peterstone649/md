# Abbreviation Reference

## Overview

This document provides a comprehensive reference for abbreviations used within the FIELDMsemantics field, particularly within the KBwikimedia knowledge base and its subdirectories.

## Core Field Abbreviations

### **KB - Knowledge Base**
- **Definition:** A centralized repository of structured information and knowledge
- **Usage:** Used to denote knowledge base directories and collections
- **Examples:**
  - `KBwikimedia` - Wikimedia knowledge base

### **KBS - Knowledge Base Sub**
- **Definition:** A specialized subdirectory within a knowledge base focusing on specific topics
- **Usage:** Used to denote specialized knowledge base subdirectories
- **Examples:**
  - `KBSwikidata` - Wikidata-specific knowledge base
  - `KBSwikipedia` - Wikipedia-specific knowledge base

## Semantic Web Abbreviations

### **RDF - Resource Description Framework**
- **Definition:** Standard model for data interchange on the web using subject-predicate-object triples
- **Purpose:** Foundation for semantic web data representation
- **Usage:** Data modeling and interchange format

### **OWL - Web Ontology Language**
- **Definition:** Language for defining ontologies and semantic relationships
- **Purpose:** Advanced knowledge representation and reasoning
- **Usage:** Ontology development and semantic modeling

### **SPARQL - SPARQL Protocol and RDF Query Language**
- **Definition:** Query language for retrieving and manipulating RDF data
- **Purpose:** Semantic data querying and analysis
- **Usage:** Database queries on semantic data

### **URI - Uniform Resource Identifier**
- **Definition:** String of characters used to identify a resource
- **Purpose:** Unique identification of entities in semantic systems
- **Usage:** Entity identification and linking

### **URL - Uniform Resource Locator**
- **Definition:** Specific type of URI that provides the means of locating a resource
- **Purpose:** Web address specification
- **Usage:** Resource location and access

### **JSON-LD - JSON for Linking Data**
- **Definition:** JSON-based serialization format for linked data
- **Purpose:** Machine-readable data representation
- **Usage:** Data exchange and web APIs

## Wikimedia Project Abbreviations

### **Q-number - Wikidata Item Identifier**
- **Definition:** Unique identifier for entities in Wikidata (e.g., Q42)
- **Purpose:** Stable reference to real-world entities
- **Usage:** Entity identification in Wikidata

### **P-number - Wikidata Property Identifier**
- **Definition:** Unique identifier for properties in Wikidata (e.g., P27)
- **Purpose:** Attribute and relationship specification
- **Usage:** Property definition and data structuring

### **L-number - Wikidata Lexeme Identifier**
- **Definition:** Unique identifier for lexemes in Wikidata (e.g., L123)
- **Purpose:** Linguistic entity identification
- **Usage:** Lexical data representation

### **F-number - Wikidata Form Identifier**
- **Definition:** Unique identifier for forms in Wikidata (e.g., F456)
- **Purpose:** Grammatical form identification
- **Usage:** Morphological data representation

### **Sitelinks**
- **Definition:** Links connecting Wikidata items to Wikipedia articles
- **Purpose:** Cross-project content integration
- **Usage:** Multilingual content linking
