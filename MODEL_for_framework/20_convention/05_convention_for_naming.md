# Convention for Naming [CONV_FOR_MFW_NAMING] **[PRIO: HIGH]**

**Version: V1.0.0** **Status: APPROVED** **Date: 2026-02-07**

## Convention statement  **[STATUS: ACTIVE]**

We establish consistent hierarchical naming standards for all framework elements to enable programmatic processing and improve discoverability.

Hierarchical naming means that general categories come first, followed by increasingly specific refinements.

### **Components**
e.g. <noun> or <nouned verb> followed by <rest of name> 


### **Examples**
```
convention for naming
template for reference of terms
template of type simple 
template ot simple 
```
ot = "of type"
